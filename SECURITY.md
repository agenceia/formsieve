# Security

Do not post credentials or personal form data in public issues. Report suspected vulnerabilities privately to the maintainer of the deployment/repository, with a minimal reproduction using synthetic data. A public security contact must be configured when the project is published.

This pre-1.0 library has automated tests but has not undergone an independent security audit. See README for trust boundaries and delivery semantics. Never put API keys in browser code. Rotate any exposed keys through the corresponding provider.
